## When you download PDFs

1. Search the verified case number or name; cross-check the full name, case period and court jurisdiction.
2. Save the public court export using the suggested PDF filename from the CSV. For multiple orders, use separate clearly named PDFs.
3. Keep multi-defendant cases distinct until the records show whether they share a docket.
4. Screen documents for sealed/confidential information and personal identifiers before sharing publicly. Remote access to some criminal filings is restricted; ask the clerk about copies.
5. Send the collected folder for a comparison of court dates, charges, pleas, convictions, dismissals and subsequent relief.

## Update policy

The original case data lives in `research/case-data.json` and the separate Constantine Petros HTML page. Add case numbers only after an official match; future import work can update this tracker and the public case pages.
